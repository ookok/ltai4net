# LTAI 4 Net 全面审计计划

## 审计概述

基于现有 `docs/audit-report.md`（2026-06-08）的发现，结合最新代码状态进行增量审计和修复。项目规模：11 个 src 项目，34 个 agent 定义，34+ 个测试文件，4 个 git submodule。

---

## 审计发现汇总

### P0 — 必须立即修复（阻塞稳定性/安全）

#### P0-1: 同步阻塞死锁风险（7 处关键）
已从 audit-report.md 更新，实际扫描结果：

| 文件 | 行号 | 问题 |
|------|------|------|
| `src/LTAI.Web/Rendering/WebChatRenderer.cs` | 98-99 | `.GetAwaiter().GetResult()` 阻塞 ASP.NET 请求线程 |
| `src/LTAI.Hpo/Samplers/TpeSampler.cs` | 33, 110 | `Task.Run().GetAwaiter().GetResult()` 死锁风险 |
| `src/LTAI.Agent/Agents/AgentDefinitionLoader.cs` | 42 | `.GetAwaiter().GetResult()` 阻塞 DI 构建 |
| `src/LTAI.Agent/Tools/GitTools.cs` | 28 | `task.Wait()` + `.Result` 死锁 |
| `src/LTAI.TUI/Program.cs` | 107 | `Task.Run(() => ... .Wait(3s))` 双重阻塞 |

#### P0-2: async void 方法（2 处）
| 文件 | 方法 |
|------|------|
| `src/LTAI.Accelerator/MainWindow.axaml.cs:88` | `OnStartClick` |
| `src/LTAI.Accelerator/MainWindow.axax.cs:153` | `OnStopClick` |

异步异常无法捕获，会导致进程崩溃。需改为 `async void` event handler 包装 `async Task`。

#### P0-3: SkipSafetyChecks 默认为 true
`appsettings.json:8` — `"SkipSafetyChecks": true`。生产环境应默认为 false。虽然 `LTAIOptions.SkipSafetyChecks` 默认值是 `false`，但 appsettings.json 显式覆盖为 true。

#### P0-4: Security header 缺少 HSTS
`src/LTAI.Web/Program.cs:109-117` — 设置了 X-Content-Type-Options、X-Frame-Options、CSP 等，但缺少 `Strict-Transport-Security` (HSTS)。对于 HTTPS 部署是安全隐患。

## 验证方案

### 验证步骤
1. **构建验证**: `dotnet build LTAI.sln` — 确保编译通过
2. **测试验证**: `dotnet test tests/LTAI.Tests` — 确保现有测试通过
3. **安全验证**:
   - 确认 `SkipSafetyChecks` 默认为 false
   - 确认 HSTS header 存在
   - 确认无同步阻塞
4. **功能验证**: 启动 Web (`dotnet run --project src/LTAI.Web`)，检查：
   - `/health` 端点返回 healthy
   - `/ready` 端点返回 ready
   - Security headers 存在
5. **回归验证**: 确保修改不影响现有功能
