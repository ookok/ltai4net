# option: paths
description: Directory path configuration. Root is AppContext.BaseDirectory.

## keys
- DataDirectory: string (default: .livingtree)
- SkillsDirectory: string (default: skills)
- ToolsDirectory: string (default: tools)
- PromptsDirectory: string (default: prompts)
- MemoryDirectory: string (default: memory)
- ModelsDirectory: string (default: models)
- LogsDirectory: string (default: logs)
- ConfigDirectory: string (default: config)
- OutputDirectory: string (default: output)
- AssetsDirectory: string (default: assets)
- WorkspaceRoot: string — Workspace root directory (fallback: CWD)
  env: LTAI_WORKSPACE
