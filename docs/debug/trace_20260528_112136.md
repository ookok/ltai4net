## 方案一：在你的本地运行持续监控脚本（推荐）

以下是分别适用于 **Linux/macOS** 和 **Windows** 的脚本，它们会每隔几秒刷新系统健康状态，直到你按下 `Ctrl+C` 或输入“停”才会结束。

### 🔹 Linux / macOS（终端脚本）
```bash
#!/bin/bash
echo "系统健康监控已启动，按 Ctrl+C 停止..."
while true; do
    clear
    echo "======== 系统健康状态 $(date) ========"
    echo "CPU 使用率: $(top -bn1 | grep "Cpu(s)" | awk '{print $2 + $4"%"}')"
    echo "内存使用率: $(free | grep Mem | awk '{printf "%.1f%%", $3/$2 * 100.0}')"
    echo "磁盘使用率:"
    df -h | grep -E '^/dev'
    echo "网络流量 (接收/发送):"
    cat /proc/net/dev | grep eth0 | awk '{print "接收: " $2 " bytes, 发送: " $10 " bytes"}'
    echo "系统负载: $(uptime | awk -F'load average:' '{print $2}')"
    sleep 3
done
```
保存为 `monitor.sh`，赋予执行权限 `chmod +x monitor.sh`，然后运行 `./monitor.sh`。  
停止方法：按 `Ctrl+C`（或在循环中加入判断，若检测到特定文件则退出）。

### 🔹 Windows PowerShell 脚本
```powershell
Write-Host "系统健康监控已启动，按 Ctrl+C 停止..." -ForegroundColor Green
while ($true) {
    Clear-Host
    $time = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    $cpu = (Get-CimInstance Win32_Processor | Measure-Object -Property LoadPercentage -Average).Average
    $mem = Get-CimInstance Win32_OperatingSystem
    $totalMem = [math]::Round($mem.TotalVisibleMemorySize/1MB,2)
    $freeMem = [math]::Round($mem.FreePhysicalMemory/1MB,2)
    $usedMem = $totalMem - $freeMem
    $memPercent = [math]::Round(($usedMem / $totalMem) * 100, 2)
    $disks = Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" | ForEach-Object {
        "$($_.DeviceID) 总容量: $([math]::Round($_.Size/1GB,2)) GB, 剩余: $([math]::Round($_.FreeSpace/1GB,2)) GB"
    }
    Write-Host "======== 系统健康状态 $time ========"
    Write-Host "CPU 使用率: $cpu%"
    Write-Host "内存使用率: $memPercent% (已用 ${usedMem}MB / 总 ${totalMem}MB)"
    Write-Host "磁盘空间:"
    $disks | ForEach-Object { Write-Host "  $_" }
    Start-Sleep -Seconds 3
}
```
停止方法：按 `Ctrl+C`。
