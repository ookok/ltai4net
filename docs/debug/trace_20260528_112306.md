## Response

快速排序（Quick Sort）是一种基于分治思想的高效排序算法，平均时间复杂度为 O(n log n)，在实际应用中常优于其他 O(n log n) 算法（如归并排序、堆排序）。下面将提供 C# 的泛型实现，并包含多种优化手段和清晰的注释。

## 1. 算法核心原理
1. 从数组中选择一个 **基准元素（pivot）**。
2. **分区（partition）**：将数组划分为两个子数组，使得左侧元素都 ≤ pivot，右侧元素都 ≥ pivot。
3. 对左右子数组 **递归** 执行上述步骤，直到子数组长度为 1 或 0。

常用分区方案有 **Hoare 分区**（效率较高，交换次数少）和 **Lomuto 分区**（代码更直观）。下方以 Hoare 方案为主，并加入三数取中优化。

## 2. 完整 C# 实现

```csharp
using System;
using System.Collections.Generic;

public static class QuickSort
{
    /// <summary>
    /// 排序入口（使用默认比较器）
    /// </summary>
    public static void Sort<T>(T[] array)
    {
        if (array == null) throw new ArgumentNullException(nameof(array));
        Sort(array, 0, array.Length - 1, Comparer<T>.Default);
    }

    /// <summary>
    /// 排序入口（支持自定义比较器）
    /// </summary>
    public static void Sort<T>(T[] array, IComparer<T> comparer)
    {
        if (array == null) throw new ArgumentNullException(nameof(array));
        if (comparer == null) throw new ArgumentNullException(nameof(comparer));
        Sort(array, 0, array.Length - 1, comparer);
    }

    private static void Sort<T>(T[] array, int low, int high, IComparer<T> comparer)
    {
        // 小数组优化：长度 ≤ 16 时改用插入排序，减少递归开销
        const int insertionThreshold = 16;
        if (high - low + 1 <= insertionThreshold)
        {
            InsertionSort(array, low, high, comparer);
            return;
        }

        if (low < high)
        {
            // 分区并获取基准最终位置
            int pivotIndex = Partition(array, low, high, comparer);
            // 递归排序左右两部分
            Sort(array, low, pivotIndex, comparer);        // 左侧（含基准）
            Sort(array, pivotIndex + 1, high, comparer);   // 右侧
        }
    }

    /// <summary>
    /// Hoare 分区（返回右侧子数组的起始下标）
    /// </summary>
    private static int Partition<T>(T[] array, int low, int high, IComparer<T> comparer)
    {
        // 三数取中：选择 low、mid、high 的中值作为 pivot，避免最坏情况
        int mid = low + (high - low) / 2;
        T pivot = MedianOfThree(array[low], array[mid], array[high], comparer);
        
        // 将 pivot 放在 low 位置（或随便一方，这里使用 Hoare 原始做法：两端向中间扫描）
        // 为了简单，这里采用“挖坑法”思路，先把 pivot 值存起来，左右交替扫描
        // 下面是标准 Hoare 分区实现，注意循环条件和交换逻辑
        int i = low - 1;
        int j = high + 1;
        while (true)
        {
            // 从左向右找第一个 ≥ pivot 的元素
            do
            {
                i++;
            } while (comparer.Compare(array[i], pivot) < 0);

            // 从右向左找第一个 ≤ pivot 的元素
            do
            {
                j--;
            } while (comparer.Compare(array[j], pivot) > 0);

            if (i >= j)
                return j;   // 返回分界点

            // 交换两个元素
            Swap(array, i, j);
        }
    }

    /// <summary>
    /// 三数取中：返回三个值里位于中间的那个（避免极端情况）
    /// </summary>
    private static T MedianOfThree<T>(T a, T b, T c, IComparer<T> comparer)
    {
        if (comparer.Compare(a, b) > 0) Swap(ref a, ref b);
        if (comparer.Compare(a, c) > 0) Swap(ref a, ref c);
        if (comparer.Compare(b, c) > 0) Swap(ref b, ref c);
        return b;
    }

    /// <summary>
    /// 插入排序（用于小数组优化）
    /// </summary>
    private static void InsertionSort<T>(T[] array, int low, int high, IComparer<T> comparer)
    {
        for (int i = low + 1; i <= high; i++)
        {
            T key = array[i];
            int j = i - 1;
            while (j >= low && comparer.Compare(array[j], key) > 0)
            {
                array[j + 1] = array[j];
                j--;
            }
            array[j + 1] = key;
        }
    }

    /// <summary>
    /// 交换数组两个元素
    /// </summary>
    private static void Swap<T>(T[] array, int i, int j)
    {
        T temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }

    /// <summary>
    /// 交换两个值
    /// </summary>
    private static void Swap<T>(ref T a, ref T b)
    {
        T temp = a;
        a = b;
        b = temp;
    }
}
```

## 3. 另一种分区方案：Lomuto 分区（更易理解，但交换次数略多）

```csharp
private static int LomutoPartition<T>(T[] array, int low, int high, IComparer<T> comparer)
{
    // 选择最后一个元素为 pivot（实际中也可结合三数取中优化）
    T pivot = array[high];
    int i = low - 1; // i 指向最后一个 ≤ pivot 的元素
    
    for (int j = low; j < high; j++)
    {
        if (comparer.Compare(array[j], pivot) <= 0)
        {
            i++;
            Swap(array, i, j);
        }
    }
    Swap(array, i + 1, high);
    return i + 1;
}
```

使用 Lomuto 分区时，`Sort` 方法需稍作调整，因为基准位于返回的索引处，左右递归区间应为 `(low, pivotIndex - 1)` 和 `(pivotIndex + 1, high)`。

    }
}

## 5. 复杂度分析

| 情况       | 时间复杂度 | 空间复杂度（递归栈） | 说明                         |
|------------|------------|----------------------|------------------------------|
| 最好情况   | O(n log n) | O(log n)             | 每次分区均匀分割             |
| 平均情况   | O(n log n) | O(log n)             | 数学期望下高度为对数级       |
| 最坏情况   | O(n²)      | O(n)                 | 已排序数组且始终选极值作 pivot |

通过**三数取中**可大幅降低最坏情况概率；**小数组切换插入排序**可减少递归深度约 1/4，并提升常数因子。

## 6. 算法稳定性与内存
- **不稳定排序**：相等元素的相对位置可能改变。
- **原地排序**：仅使用 O(log n) 递归栈内存（无额外数组分配）。

## 7. 进一步优化建议
1. **尾递归消除**：将较大子数组放于递归，较小子数组迭代处理，保证栈深度为 O(log n)。
2. **三向切分**：对含大量重复元素的情况，可将数组分为“小于/等于/大于”三部分，提升性能（Dijkstra 的“三向切分快速排序”）。
3. **使用 `Span<T>`**：在 .NET Core 2.1+ 中可利用 `Span<T>` 减少堆分配，提高性能。
4. **并行快速排序**：对大数据集可使用 `Task` 并行递归左右分区（需注意递归深度与线程开销）。
