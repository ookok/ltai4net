### 5. 错误分析

C# 是一种分号分隔语句的语言。每条语句必须以分号 `;` 结束。编译器在解析 `Console.WriteLine(...)` 后预期看到一个分号或一个新语句的开始，但遇到了 `int sum`，这不符合语法规则，因此抛出 `CS1002` 错误。

修复方法很简单：在第9行末尾加上分号：

```csharp
Console.WriteLine("Hello, World!");  // 添加分号
```

再次运行 `dotnet build` 即可成功编译并生成可执行文件。
