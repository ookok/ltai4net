### 步骤 1：创建工作树（worktree）
git worktree 允许你在同一个仓库中同时签出多个分支到不同的目录，互不干扰。我们需要创建一个指向新分支 `feature/test-branch` 的工作树。

假设你想把新工作树放在与主仓库同级的目录中，例如 `../feature-test-branch`（目录名随意，但建议有意义）。如果分支 `feature/test-branch` 还不存在，可以使用 `-b` 选项让 Git 自动创建该分支。

**运行下面的命令（二选一）：**

- **如果该分支不存在，需要新建：**
  ```bash
  git worktree add -b feature/test-branch ../feature-test-branch
  ```
- **如果分支已经存在于远程或本地，只想签出它：**
  ```bash
  git worktree add ../feature-test-branch feature/test-branch
  ```

**参数解释：**
- `add`：添加一个新的 worktree。
- `-b feature/test-branch`：创建一个名为 `feature/test-branch` 的新分支，并将其签出到新工作树。
- `../feature-test-branch`：新工作树的存放路径。建议放在仓库根目录外部，避免嵌套。
- `feature/test-branch`（不带 `-b` 时）：签出现有的同名分支。

执行成功后，你会看到类似：

- **为什么用 worktree？**  
  你可以在一个终端里继续在主分支上工作，同时在另一个终端（或 IDE）打开 `feature-test-branch` 目录进行独立开发，避免频繁 `git stash` 或切换分支带来的上下文丢失。

- **清理 worktree**  
  合并分支后，如果不再需要这个工作树，先确保没有未提交的修改，然后运行：
  ```bash
  # 先回到主仓库目录
  git worktree remove ../feature-test-branch
  ```

  ```bash

  ```

- **注意事项**  
  同一个分支**不能**同时在两个工作树中签出（会报错）。所以 worktree 非常适合用于并行开发不同的功能分支。
