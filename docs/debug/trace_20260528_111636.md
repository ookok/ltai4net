## 1. 操作系统命令行

### 1.1 Linux / macOS (bash/zsh)

利用管道或分步命令，确保文件创建并关闭之后再重命名。

```bash
# 方法一：使用 echo 和 mv
echo "Hello World" > test.txt && mv test.txt final.txt
```

- `echo "Hello World" > test.txt`：创建（或覆盖）`test.txt` 并写入内容，文件会立即关闭。
- `&&`：前一条命令成功（返回码为0）才执行下一条。
- `mv test.txt final.txt`：将文件重命名。

如果目标目录中可能已存在 `final.txt`，可使用 `mv -f` 强制覆盖（Linux）或 `mv -f`（macOS 通用）。更安全的做法是使用 `set -o noclobber` 避免意外覆盖。

### 1.2 Windows 命令提示符 (cmd)

```cmd
echo Hello World > test.txt && ren test.txt final.txt
```

- `echo Hello World > test.txt`：写入文件（默认没有引号，但 `"` 不会被输出，直接写 `Hello World` 即可）。
- `ren`：`rename` 的简写，将 `test.txt` 重命名为 `final.txt`。

### 1.3 Windows PowerShell

```powershell
"Hello World" | Out-File -FilePath test.txt -Encoding ASCII; Rename-Item -Path test.txt -NewName final.txt
```

或者更简洁（PowerShell 支持类似 Unix 语法，但重定向是 cmdlet 的包装）：
```powershell
"Hello World" > test.txt; mv test.txt final.txt
```
`mv` 是 `Move-Item` 的别名，可用来重命名。

## 2. Python

```python
import os

# 1. 创建并写入文件
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Hello World")
# 2. 重命名（with 块结束后文件已自动关闭）
os.rename("test.txt", "final.txt")
```

- `"w"` 模式：以写入模式打开文件（若不存在则新建，若存在则清空）。
- `with` 语句保证写入完成后自动关闭文件，这是重命名的前提（某些操作系统中打开的文件无法重命名）。
- `os.rename()` 直接重命名文件；如果目标文件已存在，会引发 `FileExistsError`（Windows）或覆盖（Unix）。可根据需要替换为 `os.replace()` 强制覆盖。

## 4. C 语言（POSIX 系统）

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    const char *temp_name = "test.txt";
    const char *final_name = "final.txt";

    // 1. 创建并写入
    FILE *fp = fopen(temp_name, "w");
    if (fp == NULL) {
        perror("fopen");
        return EXIT_FAILURE;
    }
    if (fputs("Hello World", fp) == EOF) {
        perror("fputs");
        fclose(fp);
        return EXIT_FAILURE;
    }
    fclose(fp);  // 关闭文件，确保缓冲区写入磁盘

    // 2. 重命名
    if (rename(temp_name, final_name) != 0) {
        perror("rename");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

- 首先 `fopen("test.txt", "w")` 创建文件，用 `fputs` 写入内容。
- 必须显式调用 `fclose()` 关闭流，否则在多数操作系统上无法重命名已打开的文件。
- `rename()` 是标准 C 函数，在 POSIX 系统上可以直接用于文件重命名。

## 5. Java

```java
import java.io.*;

public class CreateAndRename {
    public static void main(String[] args) {
        String tempName = "test.txt";
        String finalName = "final.txt";

        // 1. 写入文件（try-with-resources 自动关闭）
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(tempName))) {
            writer.write("Hello World");
        } catch (IOException e) {
            System.err.println("写入失败: " + e.getMessage());
            return;
        }

        // 2. 重命名
        File tempFile = new File(tempName);
        File finalFile = new File(finalName);
        if (tempFile.renameTo(finalFile)) {
            System.out.println("文件已重命名为 " + finalName);
        } else {
            System.err.println("重命名失败");
        }
    }
}
```

- `FileWriter` 搭配 `try-with-resources` 保证写入后流自动关闭。
- `File.renameTo()` 方法用于重命名，成功返回 `true`，但行为依赖平台（如 Windows 下目标文件存在时可能失败，而在 Unix 上会覆盖）。
