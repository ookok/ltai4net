## 1. 通用方法（使用命令行/终端）

### 🔹 Windows（命令提示符 / PowerShell）
**CMD：**
```cmd
dir *.cs
```
如果要包括子目录中的所有 `.cs` 文件：
```cmd
dir /s *.cs
```

**PowerShell：**
```powershell
Get-ChildItem -Path . -Filter *.cs
```
或简写：
```powershell
ls *.cs
```
递归列出（包含子目录）：
```powershell
Get-ChildItem -Path . -Filter *.cs -Recurse
# 或
ls *.cs -Recurse
```

### 🔹 Linux / macOS（终端 bash/zsh）
```bash
ls *.cs
```
递归列出所有子目录中的 `.cs` 文件：
```bash
find . -name "*.cs"
```
如果想限制在当前目录（不进入子目录）：
```bash
find . -maxdepth 1 -name "*.cs"
```

## 3. 使用脚本或程序列出

如果你想要把文件清单输出到文本文件或进一步处理：

**Bash 示例：**
```bash
find . -name "*.cs" > cs_files_list.txt
```

**PowerShell 示例：**
```powershell
Get-ChildItem -Recurse -Filter *.cs | Select-Object FullName > cs_files_list.txt
```

**简单的 Python 脚本：**
```python
import glob
for f in glob.glob("*.cs"):
    print(f)
# 递归版本
for f in glob.glob("**/*.cs", recursive=True):
    print(f)
```
