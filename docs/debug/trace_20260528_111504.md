## 方法一：Linux / macOS 终端命令

### 1.1 生成纯随机可打印文本（无换行）
```bash
tr -dc '[:print:]' < /dev/urandom | head -c 52428800 > large.txt
```
- `[:print:]` 包含所有可打印字符（字母、数字、标点、空格等）。
- 如果希望只包含字母数字（无空格、标点），可用 `A-Za-z0-9`：
  ```bash
  tr -dc 'A-Za-z0-9' < /dev/urandom | head -c 52428800 > large.txt
  ```
- **注意**：macOS 自带的 `head` 不支持 `-c` 参数，请先安装 GNU coreutils（`brew install coreutils`），然后使用 `ghead -c 52428800`。或者使用 `dd`：
  ```bash
  dd if=/dev/urandom bs=52428800 count=1 2>/dev/null | tr -dc '[:print:]' > large.txt
  ```
  但这样生成的是二进制数据再过滤，大小可能略小于预期（因为丢掉不可打印字节），所以推荐用 `head -c` 精确控制。

### 1.2 生成包含换行符的随机文本（每行 80 字符）
```bash
cat /dev/urandom | base64 | head -c 52428800 | fold -w 80 > large.txt
```
- `base64` 将二进制转换为可打印字符，输出只有 `A-Za-z0-9+/=`。
- `fold -w 80` 每 80 个字符插入一个换行符，最终文件会是规整的行文本。

### 1.3 使用 `openssl` 生成随机字符串
```bash
openssl rand -base64 39321600 | head -c 52428800 > large.txt
```
- `-base64` 会将二进制编码，39321600 字节的二进制编码后约等于 52428800 字节（精确计算：39321600 × 4/3 ≈ 52,428,800），但可能有多余的换行被 `head` 截断，最终大小恰好为 50 MiB。

## 方法二：Windows PowerShell

以下脚本在 PowerShell 中运行，可生成指定大小的随机 ASCII 文本文件。

### 2.1 生成可打印 ASCII（无换行）
```powershell
$size = 50 * 1024 * 1024  # 50 MiB
$file = "large.txt"
# 可打印字符范围：32..126（空格到~）
$chars = [char[]](32..126)
$rng = New-Object System.Random
$writer = [System.IO.StreamWriter]::new($file)
$written = 0
while ($written -lt $size) {
    $chunkSize = [Math]::Min(4096, $size - $written)
    $arr = 1..$chunkSize | ForEach-Object { $chars[$rng.Next($chars.Length)] }
    $writer.Write([string]::new($arr))
    $written += $chunkSize
}
$writer.Close()
Write-Host "large.txt 已生成，大小: $((Get-Item $file).Length) 字节"
```

### 2.2 生成字母数字并每 80 字符换行
如果想得到更“自然”的文本：
```powershell
$size = 50 * 1024 * 1024
$file = "large.txt"
$chars = [char[]]('ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'.ToCharArray())
$rng = New-Object System.Random
$writer = [System.IO.StreamWriter]::new($file)
$written = 0
$lineLength = 80
while ($written -lt $size) {
    $remaining = $size - $written
    if ($remaining -le $lineLength + 1) {
        # 最后一段不再换行
        $chunk = -join (1..$remaining | ForEach-Object { $chars[$rng.Next($chars.Length)] })
        $writer.Write($chunk)
        $written += $remaining
    } else {
        $chunk = -join (1..$lineLength | ForEach-Object { $chars[$rng.Next($chars.Length)] })
        $writer.WriteLine($chunk)
        $written += $lineLength + [Environment]::NewLine.Length
    }
}
$writer.Close()
```

## 方法三：Python 脚本（跨平台）

将以下代码保存为 `gen_large.py` 并运行（需要 Python 3.6+）。

```python
import random
import string

size = 50 * 1024 * 1024   # 50 MiB = 52428800 字节
# 可选字符集：大小写字母 + 数字，可自行添加 string.punctuation
chars = string.ascii_letters + string.digits

with open('large.txt', 'w') as f:
    while f.tell() < size:
        chunk_size = min(4096, size - f.tell())
        f.write(''.join(random.choices(chars, k=chunk_size)))

print(f"文件生成完毕，大小: {f.tell()} 字节")
```

- 若要在每 80 个字符后插入换行，可在循环中稍作修改：
  ```python
  line_len = 80
  with open('large.txt', 'w') as f:
      while f.tell() < size:
          remaining = size - f.tell()
          if remaining <= line_len + 1:
              f.write(''.join(random.choices(chars, k=remaining)))
              break
          f.write(''.join(random.choices(chars, k=line_len)) + '\n')
  ```

- 想要更丰富的字符（含标点、空格）：
  `chars = string.printable.replace('\n', '').replace('\r', '')`
