### 1.3 架构模式识别

- **分层/洋葱架构**: 依赖方向严格向内 (无循环依赖)
- **策略模式**: BaseAgent + IAnalysisStrategy 支持多语言多策略
- **中介者模式**: ICognitiveMesh + ILayerGovernor 认知消息总线
- **统一入口模式**: Program.cs -> EntryPoint.RunAsync(args) 所有可执行入口一致
- **插件架构**: LTAI.Tools 能力系统支持运行时注册
- **多层安全**: UnifiedSafetyGate -> PolicyAsCode -> SafetyCoordinator -> ActionGovernor

## 二、架构设计缺陷

### ❌ Critical (6项)

#### 2.1 God Object: LivingTreeSystem (1825行, 30+ 构造依赖)
**文件**: `src/LTAI.AI/Governors/LivingTreeSystem.cs`  
**问题**: 单类管理整个AI管线：意图分类、L0/L1/L2路由、ReAct循环、工具执行、预算管理、RL强化学习、元认知、验证、缓存、记忆、梦境循环、模型健康、异常报告、联邦学习、知识图谱构建、沙箱代码修复  
**修复**: 拆分为 `QueryProcessingPipeline`、`GroundingVerificationPipeline`、`BudgetManagementService`、`MemoryCoordinationService`、`SelfEvolutionService`，LivingTreeSystem 退化为薄门面

#### 2.2 Missing Interface: ILivingTreeSystem
**文件**: `src/LTAI.Agent/MAF/LTAIAgent.cs:16`  
**问题**: LTAI.Agent 直接依赖 LTAI.AI 的具体类型 `LivingTreeSystem`，无接口隔离  
**修复**: 在 LTAI.Core.Interfaces 中定义 `ILivingTreeSystem`，注入接口而非具体类型

#### 2.3 CognitiveMesh 是装饰性模式，无实际使用
**文件**: `src/LTAI.Core/Messaging/CognitiveMesh.cs`, `src/LTAI.AI/Governors/LivingTreeSystem.cs:1206-1344`  
**问题**: 虽然注入了 ICognitiveMesh，但 LivingTreeSystem 直接调用 `_input.ProcessAsync(...)` 等，完全绕过了 Mesh 的 SendAsync/BroadcastAsync。Mesh 的超时、统计、待处理跟踪全部无效  
**修复**: 要么改造管线使用 `_mesh.SendAsync(...)`，要么移除 Mesh 改为简单注册器

#### 2.4 Handshake 类型重复定义
**文件**: `src/LTAI.Core/Models/Handshake.cs:5` (record, 完整字段) vs `src/LTAI.Models/CoreModels.cs:66` (class, 缺字段)  
**问题**: 两个 `Handshake` 类型字段不一致，一个是 record 一个是 class  
**修复**: 删除 LTAI.Models.Handshake，统一使用 LTAI.Core.Models.Handshake

#### 2.5 CLI 硬引用所有部署模块
**文件**: `src/LTAI.Cli/LTAI.Cli.csproj:22-25`  
**问题**: CLI 直接引用 Host、MCP、TUI、WebApp 四个模块，即便用户只用 MCP 也必须携带 ASP.NET Core 完整负载  
**修复**: 定义 `ILTAIEntryPoint` 接口，运行时通过 MEF 或程序集扫描发现入口

#### 2.6 Configuration 绕过 IConfiguration
**文件**: `src/LTAI.Core/ServiceCollectionExtensions.cs:31-45`  
**问题**: 直接 `File.ReadAllText("appsettings.json")` + `JsonDocument.Parse` 绕过 ASP.NET IConfiguration，且与 EntryPoint.cs 中的标准配置绑定冲突（两个 IOptions<LTAIOptions> 注册并存）  
**修复**: 移除手动解析，统一使用 IConfiguration
