## 二、Skill Mesh 系统

### 2.1 五层技能体系

```
L4 (Meta)    — skill_extractor.md        (自动提取)
L3 (Domain)  — eia_water/air/noise/...   (领域知识)
L2 (Workflow)— code_review_pipeline.md   (工作流)
L1 (Task)    — build_and_verify_dsl.md   (任务)
L0 (Atomic)  — read_file/search/...
```

### 2.2 SkillRuntime 执行引擎

```
SkillLoader → Parse .md → Skill objects
     ↓
SkillRegistry → MatchByTrigger(query) → Load by domain
     ↓
SkillRuntime → SkillStepExecutor (shell/regex/code/http)
            → SkillExpressionEngine → SkillBranchEngine
            → SkillVarScope → SkillHookEngine
     ↓
ContextChain → BuildPrompt → LLM Chat → AddRound → Compact
```

### 2.3 Skill 统计

| 层级 | 技能数 | 示例 |
|------|--------|------|
| L0 (Atomic) | 16 | read_file, search_codebase, git_diff, web_search |
| L1 (Task) | 3 | build_verify_loop, eia_data_processor_dsl |
| L2 (Workflow) | 1 | code_review_pipeline |
| L3 (Domain) | 5 | eia_water_assessment, eia_air_quality, eia_noise_vibration |
| L4 (Meta) | 1 | skill_extractor |

## 四、多智能体协调系统

### 4.1 LTAICoordinator

```
RunTeam(team, goal)
  │
  ├─ 1. 解析目标 → SkillAwareDecomposer → 子任务列表
  ├─ 2. 构建 DAG → TaskQueue.Enqueue(tasks, dependencies)
  ├─ 3. 并行执行 → AgentPool.RunParallelAsync(ready_tasks)
  │     ├─ CodeAgent    (代码分析)
  │     ├─ EIAAgent     (环境评估)
  │     ├─ ChatAgent    (对话)
  │     └─ ReasoningAgent (MCTS推理)
  ├─ 4. 合成结果 → AgentPool.SynthesizeResultsAsync()
  └─ 5. 返回 TeamResult
```

### 4.2 TaskQueue 依赖感知DAG

```
Enqueue(task, dependsOn) → 构建依赖图
Complete(task) → 自动解锁所有依赖该任务的后继任务
Fail(task) → 级联标记下游任务为失败
BlockingCollection → 就绪队列消费者模式
```

### 4.3 AgentPool 并行执行

```
SemaphoreSlim(maxConcurrency) → 控制并行度
RunAgentAsync(agent, task) → 单Agent执行
RunParallelAsync(readyTasks) → 并发执行批次
SynthesizeResultsAsync() → LLM合成（优先 PromptService）
```

## 五、知识图谱与记忆系统

### 5.1 记忆架构全景

```
TemporalMemoryFabric  ──┐   (情景: 事件时间线)
StructMemory          ──┼── MemoryIndexService (跨存储索引)
SynapticMemory        ──┘   (学习: LiteDB, 奖励/反馈)
        │
AdaptiveRetentionController (根据质量调半衰期)
        │
DreamCycle (BackgroundService: 10分钟周期)
        │
KnowledgeGraph (SQLite: 长期结构化记忆) ←→ Memory Files (.md 文件系统)
```

### 5.2 HybridRecallEngine 多路召回

```
查询 → HyDE生成(假想答案嵌入) + Query2Doc(伪文档扩展) + Query分解
   ↓
4路融合: HyDE(0.35) + FTS5(0.30) + Vector(0.15) + KnowledgeGraph(0.20)
   ↓
RRF融合(k=60) → Reranker重排 → 返回结果
```

### 5.3 KnowledgeGraphAnalytics

```
PredictabilityIndex (PI) — Jaccard系数 + 度平衡
PI > 0.6 → 图遍历推理可靠
PI < 0.6 → 降级为向量搜索 + 自动提升为 Memory Files
```
