### 2.2 Skills — 自动进化闭环

```
RecordSuccess(pattern) → ≥3 successes → LLM ExtractAsync
  → SkillRegistry.Register(skill) → auto-create complete
                                    │
RecordSuccess(existingSkill) → ≥10 uses, 70% rate → Promote(L2)
  → ≥50 uses, 85% rate → Promote(L3)
  → SaveVersioned (archive before promote)
  → File relocation (l0/→l1_task/, l1/→l2_workflow/)
                                    │
RecordFailure → SkillRegistry.RecordFailure → persist .meta.json
```

### 2.3 Memory Files — 双模自适应

```
KnowledgeGraph (SQLite, PI analysis)
  │
  ├─ PI > 0.6 → Classic mode (single summary)
  └─ PI ≤ 0.6 → Files mode (multi-file), PromoteFromKG
                    │
              AgenticLoop.Think → RetrieveRelevant(task, domain)
```

### 2.4 Promat — A/B 测试

```
Epsilon-Greedy (exploration 10%): exploit best variant, explore random
Thompson Sampling: Beta(successes+1, failures+1) per variant
UCB1: SuccessRate + sqrt(2*ln(globalUses)/variantUses)

SelectBestVariant → Render → RecordFeedback → evolve PrompEvolution
```

## 三、多智能体协调系统

### 3.1 LTAICoordinator — 统一入口

```
LTAIAgent.RunCoreAsync
  │
  ├─ ShouldUseCoordinator(query) → YES
  │     └─ LTAICoordinator.RunTeamAsync(team, goal)
  │           ├─ SkillAwareDecomposer → subtask DAG
  │           ├─ TaskQueue.Enqueue(tasks, dependencies)
  │           ├─ AgentPool.RunParallelAsync(ready)
  │           └─ SynthesizeResultsAsync
  │
  └─ ShouldUseCoordinator(query) → NO
        └─ Direct ChatClientAgent.RunAsync()
```

### 3.2 AgentPool — 预热池

```
WarmUpAsync() — 预注册 code/eia/chat/reasoning with default prompts
_promptCache — 缓存重复 prompt 构造
IsWarmed check — 避免冷启动
```

### 3.3 Subagent 递归

```
LTAICoordinator.SpawnSubagentAsync(name, goal, tools, prompt)
  → 隔离会话 + 受限工具集 + RunTasksAsync → SubSession 回收

SpawnSubagentsParallelAsync(agents)
  → Task.WhenAll → LLM synthesis 合并结果
```

## 五、安全加固

### 5.1 GitHub Token 安全 (6 文件修复)

| 严重 | 问题 | 修复 |
|------|------|------|
| CRITICAL | Token in subprocess env (GIT_PASSWORD) | URL-embedded token + --quoting |
| CRITICAL | Base64 token storage on disk | DPAPI ProtectedData.Protect/Unprotect |
| CRITICAL | stderr/stdout token leak to client | SanitizeTokenOutput() |
| HIGH | DefaultAuthorizationHeader on HttpClient | GitHubAuthHandler domain-scoped |
| HIGH | A2A token prefix logged (16→4 chars) | Reduced to 4 chars |
| HIGH | ex.Message returned to client | Generic error message |

### 5.2 Shell/Service/FileSystem 加固

| 组件 | 修复 |
|------|------|
| ShellTools | 元字符拦截 (;&\|`$...) + 4096 char 限制 + 首令牌检查 |
| FileSystemTools | symlink/junction 检测 (FileInfo.LinkTarget + ReparsePoint) |
| ServiceDispatcher | 19 类型白名单 + 命名空间拦截 (System.IO/Diagnostics/Net/Reflection) |
| MdToolBridge | ILogger 日志 + ConcurrentDictionary knownMissingTools 缓存 |

### 5.3 PermissionStore + AgentProfile
