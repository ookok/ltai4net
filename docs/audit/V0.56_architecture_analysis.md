## 二、新增功能

### 2.1 P2P Skill Gossip 交换

```
SkillSyncService (5min)
  → GossipDiscovery.RunGossipCycleAsync()
    → POST /p2p/gossip (fanout peers)
    → SkillPublisher.SyncWithPeerAsync()
      → GET /p2p/skills (manifest)
      → GET /p2p/skills/{name}/download
      → SHA256 校验 → SkillRegistry.Register

Incoming:
  POST /p2p/gossip → GossipReceiver → P2PNode._knownPeers
  GET /p2p/skills → ISkillExchangeProvider.GetLocalSkillManifestAsync
  GET /p2p/skills/{name}/download → GetSkillContentAsync
```

### 2.2 Compose Tool Visualization (TUI)

- `ComposeToolView` — Spectre.Console 流程图表
- 并行/顺序步骤颜色编码 (黄/绿)
- `$step_name` 依赖关系箭头
- F11 快捷键入口, 1-9 选择工具

### 2.3 CLI 插件机制

`Program.LoadPluginAssemblies()` — 运行时扫描 `plugins/` 目录加载 `ILTAIEntryPoint`
