# UI Design Review

审查 UI 设计稿或实现是否符合设计规范。

## 1. 布局与间距
- 使用 8px 网格系统（间距是 8 的倍数）
- 响应式断点：手机 < 768px / 平板 < 1024px / 桌面 ≥ 1024px
- 内容区域最大宽度 ≤ 1200px
- 边距一致性：同类元素间距统一

## 2. 色彩
- 主色/辅色/背景色/文字色 4 层体系
- 对比度 ≥ 4.5:1（WCAG AA 标准）
- 不使用纯灰色文字（用带透明度的主色替代）
- 状态色：成功🟢 / 警告🟡 / 错误🔴 / 信息🔵

## 3. 无障碍
- 所有可交互元素有 focus 态
- 图片有 alt 文本
- 颜色不单独传达信息（配合图标/文字）
- Tab 导航顺序符合视觉顺序

## 4. 交互
- 按钮至少 44×44px（触屏友好）
- 加载状态有反馈（骨架屏 / 加载动画）
- 表单提交后显示成功/失败提示
- 操作有防误触（删除确认、不可逆操作二次确认）

## 5. 一致性
- 同一组件库，不混用不同 UI 框架
- 字体：系统字体栈 `-apple-system, "Segoe UI", sans-serif`
- 圆角：小 4px / 中 8px / 大 16px / 圆 50%
- 阴影层级：浅 0-2 / 中 4-8 / 深 12-24
