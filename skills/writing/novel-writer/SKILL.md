# Novel Writer 小说撰写

辅助小说创作，从设定到成稿。

## 1. 故事设定

在开始写作前先明确：

```
## 世界观
- 时代背景：古代/现代/科幻/奇幻
- 核心设定：独特的规则或设定

## 人物卡
- 主角：姓名/年龄/性格/动机/成长弧
- 配角：与主角的关系/作用
- 反派：动机/威胁程度/复杂性

## 核心冲突
- 主线冲突：
- 人物内心冲突：
```

## 2. 情节结构（三幕式）

```
第一幕（25%）— 建立
├── 开场：日常世界
├── 激励事件：打破平衡
└── 第一转折点：踏上旅程

第二幕（50%）— 对抗
├── 上升行动：困难逐步升级
├── 中点：重大转折
└── 低谷：看似失败

第三幕（25%）— 解决
├── 高潮：最终对决
└── 结局：新平衡
```

## 3. 写作技巧

| 技巧 | 说明 |
|------|------|
| Show, don't tell | 用行动和对话展示，而非直接说明 |
| 对话节奏 | 短句表紧张，长句表舒缓 |
| 感官描写 | 不止视觉，还有声音/气味/触觉 |
| 悬念 | 每章结尾留钩子 |

## 4. 章回结构

```
第 X 章
├── 开篇线钩（1-2段吸引读者）
├── 发展
├── 转折/发现
└── 结尾悬念
```

## 5. 输出格式

```
## 作品名

### 第 X 章 章名

正文内容...
```
