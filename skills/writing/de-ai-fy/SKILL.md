# 去 AI 化润色指南

让 AI 生成或辅助撰写的文本读起来像人类写的，消除 AI 典型痕迹。

## 1. 删除的 AI 高频词

| ❌ 删除 | ✅ 替换 |
|---------|--------|
| 在当今这个...时代 | 直接说事 |
| 值得注意的是 | _(删掉)_ |
| 不可否认的是 | _(删掉)_ |
| 毋庸置疑 | _(删掉)_ |
| 从某种意义上说 | _(删掉)_ |
| 我们需要认识到 | _(删掉)_ |
| 有着深远的影响 | _(删掉)_ |
| 综上所述 | _(删掉)_ |
| 首先/其次/最后 | 用 `•` 或自然过渡 |
| 丰富的 | 具体的 |
| 强大的 | 具体的 |
| 各种 | _(删掉或具体化)_ |
| 一系列 | _(删掉或具体化)_ |
| Moreover / Furthermore | _(删掉，除非必要)_ |
| In conclusion | _(删掉)_ |
| It is worth noting that | _(删掉)_ |

## 2. 句式调整

- ❌ **长定语**：`这是一个基于深度学习的用于中文文本分类的模型`
- ✅ **短句**：`这个模型用深度学习做中文文本分类。`

- ❌ **被动语态**：`该功能被设计用于提升性能`
- ✅ **主动语态**：`这个功能用来提升性能`

- ❌ **模棱两可**：`可能也许大概可以提升一定程度的性能`
- ✅ **直接**：`能让性能提升 30%`

- ❌ **陈词滥调**：`在这个充满挑战的数字时代`
- ✅ **直接说事**：`2025 年，AI 编码助手已经普及`

## 3. 加入人味

写完之后做以下检查，至少加一个：

- ✅ **个人观点**：`我觉得...` / `我比较喜欢...` / `踩过坑...`
- ✅ **具体数字**：`跑了 3 次，每次都挂在第 47 步`
- ✅ **吐槽**：`这个 API 设计得真难用...`
- ✅ **口语化**：`说白了就是...` / `说白了，这玩意不好使`
- ✅ **简短**：能一句话说完不说两句

## 4. 检查清单

写完之后逐条核对：

- [ ] 删掉了所有 AI 高频套话
- [ ] 没有「首先/其次/最后」的八股结构
- [ ] 每句话不超过 30 个字（非必须，但可做参考）  
- [ ] 至少有一处口语化表达
- [ ] 不追求「全面」，只讲重点
- [ ] 读起来像一个人在说话，不是在念报告
